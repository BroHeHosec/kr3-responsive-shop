# Учебный frontend-проект — KR3: адаптивная вёрстка

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина.

Репозиторий КР №3: `kr3-responsive-shop`. Проект создан на основе HTML/CSS-проекта КР №1 (не Bootstrap-версии КР №2) и посвящён адаптивной вёрстке без CSS-фреймворков.

## Структура проекта

- `index.html` — главная страница: hero-блок, преимущества, популярные товары, FAQ, форма заявки;
- `catalog.html` — каталог с боковым блоком фильтров и сеткой товаров;
- `product.html` — карточка товара: изображение в `<picture>`, бейдж «Хит», описание, таблица характеристик в `.table-wrapper`, цена, кнопки заявки;
- `order.html` — страница оформления заявки с формой и сообщением об успешной отправке;
- `contacts.html` — контактная информация и ссылка на форму заявки;
- `css/style.css` — базовые стили: БЭМ-классы, CSS-переменные, Flexbox / Grid, состояния;
- `css/responsive.css` — адаптивные стили по подходу Mobile First: медиазапросы `min-width`, адаптивные контейнеры, шапка, hero, сетка карточек, каталог, изображения, формы и таблицы;
- `js/main.js` — открытие и закрытие модального окна, обработка форм (в модалке и на `order.html`), валидация, управление фокусом, кнопка «Наверх»;
- `images/` — изображения проекта.

## Используемые технологии

## Текущий статус

Сайт состоит из пяти страниц: главной, каталога, карточки товара, заявки и контактов. На всех страницах используются общие шапка, меню и подвал. Добавлены якорные ссылки, хлебные крошки, уникальные заголовки и описания страниц. Каталог организован через именованные области CSS Grid: фильтры слева, товары справа. Меню и содержимое карточек выровнены через Flexbox, отступы заданы через `gap`. Сохранены модальное окно оформления заявки и базовая валидация формы.

В рамках КР №3 проект адаптирован под мобильные устройства без Bootstrap: подключён `css/responsive.css`, применены медиазапросы, responsive images, адаптивные формы и таблицы.

## Почему КР №3 выполняется не на Bootstrap-проекте

Bootstrap уже содержит готовую адаптивную сетку и компоненты. Чтобы продемонстрировать самостоятельное владение медиазапросами, Flexbox, Grid, responsive images и адаптацией сложных блоков, КР №3 выполняется на основе проекта КР №1 (`kr1-html-css-shop`), а не Bootstrap-версии КР №2.

## Адаптивность: что сделано

### Подход Mobile First

Базовые стили в `css/responsive.css` рассчитаны на мобильный экран. Улучшения для планшетов и desktop добавляются через медиазапросы `min-width`:

- `min-width: 640px` — сетка карточек в 2 колонки;
- `min-width: 768px` — меню в строку, sticky-шапка, каталог в 2 колонки (фильтры + товары), форма в 2 колонки;
- `min-width: 900px` — двухколоночный hero-блок;
- `min-width: 1024px` — сетка карточек в 3 колонки;
- `min-width: 1200px` — сетка карточек в 4 колонки.

### Базовый каркас

- `box-sizing: border-box` для всех элементов;
- `img, video { max-width: 100%; height: auto; }` — изображения не выходят за пределы контейнера;
- `body { overflow-x: hidden; }` — временная защита от горизонтального скролла;
- `width: min(100% - 32px, 1200px)` и `margin-inline: auto` — адаптивные контейнеры;
- `padding-block: clamp(24px, 5vw, 64px)` — адаптивные отступы секций.

### Шапка и навигация

- на мобильном экране меню в колонку, шапка `position: static`;
- с 768px меню в строку (`flex-direction: row`, `flex-wrap: wrap`), шапка `position: sticky` с `z-index: 100`.

### Hero-блок

- на мобильном экране одноколоночный;
- с 900px — двухколоночный (`grid-template-columns: minmax(0, 1fr) minmax(320px, 520px)`);
- заголовок адаптивный через `clamp(28px, 7vw, 56px)`;
- изображение в `<picture>` с версиями для mobile / tablet / desktop.

### Сетка карточек

- по умолчанию 1 колонка;
- с 640px — 2 колонки;
- с 1024px — 3 колонки;
- с 1200px — 4 колонки;
- `min-width: 0` у карточек и `overflow-wrap: anywhere` у заголовков/описаний — защита от переполнения.

### Каталог и фильтры

- на мобильном экране фильтры над списком товаров (`grid-template-areas: "filters" "products"`);
- с 768px — фильтры слева (260px), товары справа (`grid-template-areas: "filters products"`).

### Responsive images

- `max-width: 100%`, `height: auto` для всех изображений;
- `srcset` и `sizes` в карточках товаров на главной и в каталоге;
- `<picture>` с `source media` на странице товара и в hero-блоке;
- `width` и `height` указаны для резервирования места;
- `loading="lazy"` для изображений ниже первого экрана.

### Форма заявки

- поля в одну колонку на мобильном экране;
- `min-height: 44px` для полей — удобно нажимать на сенсорном экране;
- с 768px форма в 2 колонки, широкие поля (`.order-form__field--wide`) и кнопки (`.order-form__actions`) растягиваются на обе колонки;
- модальное окно ограничено по ширине (`width: min(100% - 32px, 640px)`) и высоте (`max-height: calc(100dvh - 32px)`).

### Адаптивная таблица характеристик

- таблица обёрнута в `.table-wrapper` с `overflow-x: auto` и `-webkit-overflow-scrolling: touch`;
- `min-width: 640px` у таблицы — на узком экране появляется горизонтальная прокрутка, страница не ломается.
